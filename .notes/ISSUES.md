# Open issues

- **The OpenGL renderer asserts at the main menu in a debug build.** With no game started, `GlWorld::describe` calls `Water::update(0, false)` every frame: `World::update` never runs at `State_NoGame`, so `FrameDescriber` keeps its default `mPaused = false`. `RippleSimulation::update` then calls `MWRender::isWading` for the player's emitter, which `World::setupPlayer` added at start, and the player has no cell: `PtrBase::getCell` fails `Assertion 'mCell'` (`ptr.hpp:81`). Seen at `4d878d8ca8`, `./omw exec ./openmw` with `[RTX] enabled = false`, under gdb; a window the compositor hides draws no frames and does not reach it.

- **A build with validation on by default aborts where the Vulkan loader finds no device.** The loader reports `setup_loader_term_phys_devs:  Failed to detect any valid GPUs in the current config` through the debug messenger as an error, and `validation.cpp`'s `onMessage` takes it for a validation error and aborts ("validation errors are fatal when the layers are enabled"), before `PhysicalDevice::select` can answer `Unsupported`. Seen in the debug flavour with `VK_DRIVER_FILES` naming RADV on a machine with no AMD card; the release build falls back to OpenGL.
