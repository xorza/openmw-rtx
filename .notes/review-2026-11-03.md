# Code review — ray tracer and diff with upstream (2026-11-03)

Scope: all of `components/rtx`, `components/rtxvulkan`, `components/myguirtx`, `apps/openmw/mwrender/rtx`,
`apps/rtxtool`, and the diff with upstream (merge-base `16b14001cf`) in `apps/`, `components/`, `cmake/`,
the CMake files, `files/settings-default.cfg` and `files/data-mw`. 13 reviewers read their parts in full,
and one first pass read samples. The review has 28 findings: 3 medium and 25 low. It has no high-impact
finding. One more item was dropped after a second check.

Status of each finding:

- **checked twice** — a reviewer confirmed it, and a second read of the code confirmed it again.
- **confirmed** — a reviewer followed it through the callers and the producers.
- **plausible** — the code path is real, but no shipped content or target driver takes it now.

**Order.** Each batch holds the findings one change touches, so it is one edit and one verification
cycle. The batches are ordered by harm times reach: what vanilla content shows first, then what common
content or every frame meets, then what only a mod or a driver off the target list meets, and the
documents last. Inside a batch, the item that the others depend on comes first.

Each item has a **Fix**: the structural change, with its source where the field has an established answer.

## 1. Visibility gates — medium

- **`apps/openmw/mwscript/visibilityrun.cpp:297`, `:369` `VisibilityRun::run`** — confirmed, and found in
  vanilla content. `MenuMode` is asked both ways. A script that starts with `if ( MenuMode == 1 ) return
  endif` keeps the reference standing under one answer and toggles it under the other, so the gate is
  Undecided and stands as ungated. Bloodmoon's `stal1script`, `stal2script`, `stal3script` and
  `stoneulfgarscript` open with this guard: the standing stones that `visibilitygates.hpp` names as a gate
  target. The test at `visibilitygates` line 318 checks `MenuMode` only with a script that toggles nothing
  after the guard.
  **Fix:** `MenuMode` is a constant 0 in a run, not an asked event: the distance is seen with the menus
  closed, which is the rule the test's own message states ("a menu says nothing of the reference"). This
  also halves the ways such a script runs. Extend the test with a guarded script that toggles.
- **`apps/openmw/mwscript/visibilityrun.cpp:66`** — confirmed. A run starts every local at 0 (a stated rule,
  `visibilitygates.hpp`), and a decided gate wins over the saved enabled flag (`CellPlacer::standsBy`).
  Dialogue or another script can write a reference's local (`set "ref".state to 1`) while its cell is not
  loaded. The gate then decides from a 0 that the reference does not have.
  **Fix (decision 3):** at build, list the locals written from outside a script: every member write in the
  compiled scripts and in the dialogue results, found with the compiler's own scanner and not by text
  match. A run that reads such a local ends Undecided. **Open:** Lua writes a local through
  `getLocalScript(obj).variables`, which no scan of the content can see. That writer needs its own answer.
- **`apps/openmw/mwscript/visibilitygates.cpp:244` `VisibilityGates::moved`** — confirmed. `GameHour` is
  watched for whole hours only (a stated trade-off, `Watched`), so `GameHour >= 19.5` answers up to one game
  hour late.
  **Fix (decision 4):** a script that reads `GameHour` also wakes when the hour passes any number literal
  of the script, taken from the compiled script's literal table. This is a superset of its limits, so it is
  never late for a test against a literal, in any expression order, and it costs only a wake for a literal
  that is not a limit. A test against a variable stays hourly. The same idea as a next-event time in a
  discrete-event simulation: wake only where the result can change.

## 2. Texture encoding on the device — medium

- **`components/rtxvulkan/shaders/texture/bc7encode.comp:170` `storedNearest`** — checked twice. BC7 mode 6
  shares one low bit across R, G, B and A for each end point. A BC5 normal map has blue 0 and alpha 255,
  both bits cost 1 on B and A, so R and G choose the bit, and blue becomes 1. `decodeNormal`
  (`lib/normaldecode.glsl:18`) reads any blue above 0 as a stored Z and returns z ≈ −0.99. The map is a BC5
  map with one level, wider than 512 texels, that `TextureArrival::recordEncodes` sends through the device
  chain. `texturing.glsl:339` and `normalspread.comp:81` read it.
  **Fix (decision 1):** the chain keeps the file's format family: a two-channel source is encoded to BC5
  (two BC4 blocks, each channel with its own end points), and BC7 stays for colour. `TextureData` picks the
  format once, from the source format. Sources: Castaño, "Normal Map Compression Revisited"
  (ludicon.com); Hargreaves, "DXT compression for normalmaps"; Betsy and Compressonator encode BC4/BC5 on
  the GPU.
- **`components/rtxvulkan/texture/bc7encodepass.cpp:52` `Bc7EncodePass::record`** — plausible. One 1-D
  dispatch encodes every level, and no code reads `maxComputeWorkGroupCount`. An 8192² texture with no mips
  needs about 87,381 groups, and Vulkan guarantees 65,535.
  **Fix:** one helper in the backend for a dispatch whose count grows with content: a 2-D grid of
  `min(count, limit.x)` by `ceil(count / limit.x)` groups, and one GLSL function that gives the linear group
  index and stops the groups past the count. The BC7 kernel and the new BC5 kernel both use it, so the limit
  is read in one place.

## 3. `GameHour` writes and the cut — medium

- **`apps/openmw/mwworld/worldimp.cpp:562` `World::noteHourWritten`** — checked twice. A Lua global script
  that sets `gamehour` reaches `RtxRenderer::notifyCut` (`rtxrenderer.cpp:816`) on the Lua worker, while the
  main thread is in `renderFrame` (`engine.cpp:321-325`). A debug build aborts on
  `mPhase.expect(Phase::Between)`, and a release build has a data race on `mLoss`.
  **Fix:** derive the cut and do not hook the write. Each frame, on the main thread, `World::updateWeather`
  compares the hour with the hour the last frame left and calls `DateTimeManager::jumps` with the frame's
  own step, beside the teleport cut it already raises there (`worldimp.cpp:3392`). One place covers every
  writer: mwscript, Lua, the console and the harness. The hooks in `setGlobalFloat` and `setGlobalInt` go,
  and the AGENTS.md entry that names `World::noteHourWritten` changes with them. A Lua write in frame N is
  seen in frame N+1, as a Lua teleport is.

## 4. Light-transport inputs in the shaders — low

Both items change what every frame shows, so they share one `./omw shot` and `./omw noise` cycle.

- **`components/rtxvulkan/shaders/lib/shading.glsl:328`, `:377` `startGather`** — confirmed.
  `receiverStretch` gets `litCosine` (`lights.glsl:372-377`): the mapped normal times `terminatorShare`,
  or 0.5 transmission on a sheet's far side. Its doc (`shading.glsl:57-63`) describes the geometric cosine.
  A back-lit leaf's penumbra is 2× too wide, and on a normal-mapped floor under a 30° sun the stretch goes
  from 1.3 to 5 texel by texel, where the plane gives 2. This sets the shadow denoiser's reach.
  **Fix:** the picked sky and lamp records carry the geometric cosine (the geometric normal, absolute on a
  sheet) beside the lit cosine, computed once where the lit cosine is, and `receiverStretch` takes it. A
  penumbra is a function of the receiver's plane and the occluder distance (Fernando, PCSS, 2005), not of
  the shading normal.
- **`components/rtxvulkan/shaders/lib/traversal.glsl:426` `candidateStops`** — confirmed. Shadow rays and
  bounce rays take a see-through surface's opacity, and also its alpha cut, from the diffuse alpha alone.
  `resolve` multiplies the opacity by the dark map's alpha (`:1537`), and `objects.frag` multiplies it in
  before `alphaTest`. The docs at `sampledOpacity` (`:180`) and `Surface::mOpacity` (`:1104`) say these are
  one number. The comment at `:423` measured the dark-map read at 3% of the trace, as code in every shadow
  ray's loop.
  **Fix:** one function gives a surface's alpha, and both `resolve` and `candidateStops` call it. The dark
  map's read compiles in only when the scene holds a material whose dark map has alpha below 1, through a
  specialization constant of the kernel tuple. The preprocessor already knows each texture's alpha. A
  vanilla scene then pays nothing, and every scene is right. Source: specialization constants
  (Vulkan spec, "Specialization Constants") as the established way to compile a case out.

## 5. Mirror — low

- **`components/rtx/mirror/chainkeys.cpp:23` `ChainKeys::under` / `retire`** — confirmed. A
  `StateSetUpdater` switches a node between two copies of its state set at each update
  (`statesetupdater.cpp:36-39`). The walk keys each copy, and no material uses those keys. On each frame
  after a material is freed, `retire` erases the copy that the walk did not meet, and the next frame makes
  it again: a `new osg::StateSet` and a map insert, for each such node in view.
  **Fix:** the game's two alternating copies never enter the key chain. A node that an updater drives is
  keyed by the mirror's own copy, which the walk already pushes after the node's set and which the
  updater rewrites in place (the accepted `StateSetUpdater::getGeneration` entry). The walk does not push
  the game's copy for such a node, and `join` keys the mirror's copy by itself, as it keys a controller's.
- **`components/rtx/mirror/frozenroots.hpp:59` `FrozenRoots::Face`** — plausible. `Face::of` keeps the
  first child and the state set as raw pointers (`frozenroots.cpp:13-24`), so a new object at a freed
  address compares equal.
  **Fix:** the face holds `osg::ref_ptr`s, as the identity keys do (`mirroridentity.hpp:21-24`). A held
  object cannot be freed, so its address cannot be reused.

## 6. What follows a font refit — low

- **`apps/openmw/mwgui/windowmanagerimp.cpp:1367` `WindowManager::fitFonts`** — confirmed. After a raster
  change, `requestMapRender(playerCell)` changes nothing on screen. An exterior segment returns early at the
  neighbour flags (`localmap.cpp:199-220`). An interior segment gets a new view, but each `MapEntry` keeps
  the old one (`mapwindow.cpp:608-631` fetches only when the entry holds none).
  **Fix:** the raster is part of what "drawn" means: `LocalMap` treats a segment drawn at another raster as
  not drawn, so a request draws it again. `MapWindow` holds no view of its own between updates: it compares
  its entry with the view `LocalMap` has now. A copy that is compared with its source cannot go stale.
- **`apps/openmw/mwgui/journalwindow.cpp:357`** — confirmed. After the options overlay opens once, the three
  topic-index pages keep their book. A refit drops all five pages, the shown pages' retypeset clears only
  their own flags, and each topic-index page calls `retypeset()` again: 3 to 4 typesets for one change.
  **Fix:** the owner asks for a retypeset, one time, and the pages do not. The journal and the dialogue
  history each register one time with the font registry as the owner of their books. A page only drops its
  book. Five callbacks to one owner were five routes to one result.

## 7. Moon phase before the first weather update — low, not on the accepted list

- **`apps/openmw/mwrender/renderingmanager.cpp:314` `skyGetMasserPhase` / `skyGetSecundaPhase`** —
  confirmed. They read `SkyState::mMoons`, which holds `Phase::Full` (so 4) from `= {}`
  (`skystate.hpp:67`) until `WeatherManager::update` runs outdoors (`weather.cpp:895`). Upstream returned 0
  until the sky dome existed.
  **Fix (decision 5):** at a new game and at a load, `WeatherManager` sets the moons through the same
  `MoonModel::calculateState` call the outdoor update makes, so the first answer is the date's phase. After
  that, the last exterior's phase stays, as in vanilla (UESP, Tes3Mod:GetMasserPhase). This goes on the
  accepted list as an approved upstream fix.

## 8. Device scene and its sync — low

All three come out under synchronisation validation, so they share one validation run.

- **`components/rtxvulkan/scene/devicescene.cpp:59` `DeviceScene::DeviceScene`** — plausible. The
  constructor records the skin pass once per pose copy into the same posed normals and tangents, behind a
  barrier with a read-only destination. `SkinPass::recordArrived` has the write-to-write hand-over for the
  same case. The staged bind normals that `SceneBuffers::writeMeshes` writes, before the skin dispatch
  overwrites them, have the same shape (`orderStagedWrites` hands over to `MEMORY_READ` only).
  **Fix:** the constructor calls the one per-copy routine that `recordArrived` uses, so one route holds the
  hand-over. `orderStagedWrites` names the consumer's real access, a write included.
- **`components/rtxvulkan/scene/bottomlevelstore.hpp:44` `Backlog::settle`** — plausible. `mAsked` clears
  its read prefix only when all of it is read. While each frame asks a new question, it grows without a
  bound, with `push_back` reallocations on the frame path. `mAnswered` has the same shape.
  **Fix:** a fixed-capacity ring, the established bounded FIFO. Its capacity is the questions that can be in
  flight (frames in flight times the structures one placement asks about), and a full ring is a handled
  case: no new question until one is answered.
- **`components/rtxvulkan/device/memory/image.cpp:357` `Image::buildMips`** — confirmed, latent. An image
  with one level is skipped, so its compute write has no barrier before a sampled read, which the doc in
  `image.hpp` promises.
  **Fix:** one path for every image. A one-level image is a chain of one level and gets the same final
  hand-over.

## 9. Traced ground: a reference moved into another cell — low

- **`apps/openmw/mwrender/rtx/tracedground.cpp:55` `TracedGround::blacklistReference`** — plausible.
  `World::moveObject` (`worldimp.cpp:1136`) passes the Ptr from before the move, so the reference's new cell
  is computed from the new position in the old cell's worldspace. A reference moved into an interior whose
  coordinates fall in its old exterior square stays standing in the distance. Upstream's own paging needs
  that old Ptr: `RenderingManager::pagingBlacklistObject` reads the old cell's grid to find the chunk to drop.
  **Fix:** the seam tells a move as a move, from one Ptr to the other (`Renderer::referenceMoved(from, to)`
  or the same call with both). The rasterizer reads `from` as upstream does. The ray tracer compares the
  destination cell with the content cell as cells, worldspace and grid, and an interior is away.

## 10. Vulkan device — low, latent

- **`components/rtxvulkan/device/commands.cpp:614` `CommandPool::submitWithDeferred`** — plausible. With
  `mWatchSubmits`, each deferred batch is submitted alone first, and `mDeferred` is cleared only after the
  main submit succeeds (`:699`). A throw at `:658` leaves executed one-time buffers to be submitted again.
  **Fix:** the batches leave `mDeferred` (`std::exchange`) before the first call that can fail, so a throw
  cannot see them again: ownership moves before the fallible step.
- **`components/rtxvulkan/device/zonecounters.cpp:46` `ZoneCounters::ZoneCounters`** — plausible. Counters
  are picked by pass count, and `VkPerformanceCounterKHR::scope` is not read. `GpuTimer` begins a query in
  the middle of a command buffer (`gputimer.cpp:124`), which a command-buffer scope forbids
  (`VUID-vkCmdBeginQuery-queryPool-03224`). ANV and Turnip report that scope.
  **Fix:** only `VK_PERFORMANCE_COUNTER_SCOPE_COMMAND_KHR` counters are picked. A driver with none reports
  that it has no zone counters, which the API already allows for a driver without the extension.

## 11. SPIR-V pinning — low, latent

- **`components/rtxvulkan/spirv/spirvpin.cpp:279` `isUnpinnable`** — confirmed. The doc refuses every float
  atomic and subgroup reduction, but `OpAtomicFMinEXT`, `OpAtomicFMaxEXT`, `OpGroupNonUniformFMin/FMax` and
  `OpGroupFMin/FMax` pass.
- **`components/rtxvulkan/spirv/spirvpin.cpp:521` `Pinner::survey`** — confirmed. `RelaxedPrecision` is
  refused from `OpDecorate` only, and accepted from `OpMemberDecorate`.
  **Fix for both:** default deny. The pass keeps a list of the float operations it knows to be exact or
  pins, and refuses every other operation with a float result or float operand, so a new opcode stops the
  build. Decorations are read in one place for `OpDecorate` and `OpMemberDecorate`. A list of what is
  allowed is the established form of a validator that must not miss a case (OWASP, input validation:
  allowlist over denylist).

## 12. Measurement — low

- **`apps/rtxtool/instruments/frametimes.cpp:497` `GpuBreakdown::add`** — confirmed. A counter row reserves
  one reading per frame, but a reading is added per span, before the merge to one per frame (`:504`). A zone
  that opens more than once in a frame reallocates in a measured frame.
  **Fix:** spans add into a per-frame scratch of one slot per zone, and the row takes one reading when the
  frame closes, so the reservation holds by construction.
- **`apps/rtxtool/cameradriver.cpp:243` `CameraDriver::fly`** — confirmed. `mArrived` is set on the step
  after the eye reaches `route.mTo`, so a route that arrives early measures one more frame at rest.
  **Fix:** the step that lands on `mTo` sets `mArrived`.
- **`components/rtx/renderer/nullrenderer.cpp:179` `NullRenderer::resultOf`** — confirmed. The null backend
  resolves the reconstruction when the result is collected, from the profile. It ignores
  `FrameOptions::mReconstruction` and a later `setUpscale`. `VulkanRenderer::traceFrame` resolves it at trace
  time.
  **Fix:** the core resolves a frame's reconstruction once, when the frame is traced, and the frame record
  carries it. Both backends read that one value, so they cannot differ.

## 14. OpenGL water cull — low, OpenGL renderer only

- **`apps/openmw/mwrender/glworld.cpp:450` `GlWorld::describe`** — plausible. The water's height-cull

## 15. Shader digest can throw — low

- **`components/rtx/renderer/shaderdirectory.cpp:27` `Rtx::digestShaders`** — plausible. The `error_code`

## 16. Documents — low

- **Occluded window** (`components/sdlutil/sdlinputwrapper.cpp:361`, `engine.cpp:171`) — confirmed. An

## Decisions (2026-11-03)

- **BC5 normal maps are encoded to BC5** (batch 2). Refused: a two-channel flag in the material (mode 6
  still codes R and G together), and a special low bit in the BC7 encoder (alpha changes, the exact 0 stays
  fragile).
- **An occluded window pauses, as now** (batch 16). Refused: drawing stopped with the game running, and a
  setting.
- **A gate whose script reads a local that something outside writes is Undecided** (batch 1). Refused: a
  gate per reference seeded from the saved locals (cost), and keeping the rule. Lua writes are still open.
- **A gate wakes at the literals of a script that reads `GameHour`**, and at the whole hour (batch 1).
  Refused: a step of one game minute (60 times the runs), and keeping the hour.
- **The moon phase starts from the date** (batch 7), an approved upstream fix for the accepted list.
- **The shared auto maps are accepted** (batch 13) and go on the accepted list.
- **LightGrid becomes incremental**: lamps in recycled slots, a grid anchored in world space with a fixed
  cell and hashed over the cells in use (Teschner et al. 2003; NVIDIA SHaRC's hash grid), run blocks
  recycled by size class. Refused: measuring first, since the rule holds whatever the number, and keeping
  the rebuild. This is a work item of its own, not a finding batch, and it goes after the batches.
