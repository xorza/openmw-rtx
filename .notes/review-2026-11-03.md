# Code review — ray tracer and diff with upstream (2026-11-03)

Scope: all of `components/rtx`, `components/rtxvulkan`, `components/myguirtx`, `apps/openmw/mwrender/rtx`,
`apps/rtxtool`, and the diff with upstream (merge-base `16b14001cf`) in `apps/`, `components/`, `cmake/`,
the CMake files, `files/settings-default.cfg` and `files/data-mw`. 13 reviewers read their parts in full,
and one first pass read samples. The review found 29 items: 4 medium, 25 low. It found no high-impact item.

Status of each finding:

- **checked twice** — a reviewer confirmed it, and a second read of the code confirmed it again.
- **confirmed** — a reviewer followed it through the callers and the producers.
- **plausible** — the code path is real, but the reviewer found no shipped content or driver that takes it.
- **unverified** — the first pass found it, and no reviewer checked it after that.

Batches group the findings that touch the same code. The batches are in order of impact.

## 1. A Lua write of `GameHour` calls the ray tracer from the Lua thread — medium

- **`apps/openmw/mwworld/worldimp.cpp:562` `World::noteHourWritten`** — checked twice.
  A Lua global script that sets `gamehour` goes through `mwscriptbindings.cpp:339` (`__newindex`) →
  `setGlobalVariableValue` → `World::setGlobalFloat` → `noteHourWritten` → `RenderingManager::notifyCut` →
  `RtxRenderer::notifyCut` (`rtxrenderer.cpp:816`). Global scripts run on the Lua worker
  (`[Lua] lua num threads = 1`, the default), between `allowUpdate` and `finishUpdate`, while the main thread
  is in `renderFrame` (`engine.cpp:321-325`). A debug build aborts on `mPhase.expect(Phase::Between)`.
  A release build has a data race on `mLoss`: the cut is lost or applied one frame early.

## 2. An occluded window pauses the whole game — medium

- **`components/sdlutil/sdlinputwrapper.cpp:361`, `sdlvideowrapper.cpp:62` `isWindowShown`** — checked twice.
  `isWindowShown` is false for `SDL_WINDOW_OCCLUDED`. `Engine::frame` (`engine.cpp:171`) reacts to a window
  that is not shown with `pausePlayback()` and returns before the game logic. Upstream paused only on
  `SDL_WINDOWEVENT_HIDDEN`. A window that another window covers, or that is on another virtual desktop,
  now stops the simulation, the scripts and the music. AGENTS.md promises only that such a window draws
  nothing (`SDLUtil::isWindowShown`).

## 3. BC7 encoder — medium

- **`components/rtxvulkan/shaders/texture/bc7encode.comp:170` `storedNearest`** — checked twice.
  BC7 mode 6 keeps one low bit for each end point, shared by R, G, B and A. A BC5 normal map has blue 0 and
  alpha 255. Both bits give an error of 1 on B and A, so R and G choose the bit. With bit 1, blue is stored
  as 1. `decodeNormal` (`lib/normaldecode.glsl:18`) reads any blue above 0 as a stored Z and returns
  z = 2/255 − 1 ≈ −0.99. The normal points into the surface in about half of the blocks. This affects a BC5
  normal map with one mip level and more than 512 texels wide, which `TextureArrival::recordEncodes` sends
  through the mip chain and the BC7 encoder. `texturing.glsl:339` and `normalspread.comp:81` read it.
- **`components/rtxvulkan/texture/bc7encodepass.cpp:52` `Bc7EncodePass::record`** — plausible.
  One 1-D dispatch encodes every level, and no code checks `maxComputeWorkGroupCount`. A texture of
  8192² with no mips needs about 87,381 groups, and Vulkan guarantees 65,535. NVIDIA, RADV and AMDVLK report
  more.

## 4. Visibility gates — medium

- **`apps/openmw/mwscript/visibilityrun.cpp:369` `VisibilityRun::run`** — confirmed.
  `MenuMode` is asked both ways (`:297`). A script that starts with `if ( MenuMode == 1 ) return endif`
  keeps the reference standing under one answer and toggles it under the other. The answers disagree, so
  the gate is Undecided and stands as ungated. The distance then shows the stage the script removes, for
  every vanilla script and mod script with this guard. The test at `visibilitygates` line 318 checks
  `MenuMode` only with a script that toggles nothing after the guard.
- **`apps/openmw/mwscript/visibilityrun.cpp:66`** — unverified.
  A gate runs the script with all locals at zero, and shares one result for every reference with that
  script. A script whose enable/disable reads its own locals (set by dialogue, another script or the save)
  gets a gate decided from state the reference does not have.
- **`apps/openmw/mwscript/visibilitygates.cpp:244`** — unverified.
  The gates watch `GameHour` only for whole-hour changes (`floor(now) != floor(value)`). A script that
  compares `GameHour` with 19.5 runs again only at 20.0, up to a game hour late.

## 5. Moon phase before the first weather update — low, not on the accepted list

- **`apps/openmw/mwrender/renderingmanager.cpp:314` `skyGetMasserPhase` / `skyGetSecundaPhase`** — confirmed.
  They read `SkyState::mMoons`, which is `{}` (`skystate.hpp:67`, `Phase::Full`, so 4) until
  `WeatherManager::update` runs outdoors (`weather.cpp:895`). Upstream returned 0 until the sky dome
  existed. A new game, or a save loaded indoors, gives scripts a full moon until the player goes outdoors.

## 6. Crash monitor hang report — low

- **`components/crashcatcher/crashpadmonitor.cpp:624`** — unverified.
  Since `af2e1551fe`, `mReportDue` is set when the box is posted, not at the click. A player who clicks End
  more than 10 s after the box appears gets no wait for the report, and the game ends while Crashpad can
  still write it.

## 7. What follows a font refit — low

- **`apps/openmw/mwgui/windowmanagerimp.cpp:1367` `WindowManager::fitFonts`** — confirmed.
  After a raster change, `requestMapRender(playerCell)` changes nothing on screen. For an exterior,
  `LocalMap::requestMap` returns early at the neighbour flags (`localmap.cpp:199-220`). For an interior,
  `draw()` makes a new `segment.mView`, but each `MapEntry` keeps the old view: `mapwindow.cpp:608-631`
  fetches a view only when `entry.mMapView` is null, and only `setActiveCell` clears it. The comment at
  `:1362` says the tiles are drawn again.
- **`apps/openmw/mwgui/journalwindow.cpp:357`** — unverified.
  After the options overlay opens once, the three topic-index pages stay in book mode. A refit drops
  them, and each one's `PageDisplay::refit` calls `retypeset()` again: the journal is typeset 3 to 4 times
  for one change, which breaks the contract stated in `bookpage.cpp`.

## 8. Penumbra stretch from the lit cosine — low

- **`components/rtxvulkan/shaders/lib/shading.glsl:328` and `:377` `startGather`** — confirmed.
  `receiverStretch` gets `litCosine` (`lights.glsl:372-377`): the mapped normal times `terminatorShare`,
  or `SHEET_TRANSMISSION` (0.5) on a sheet's far side. Its doc (`shading.glsl:57-63`) describes the
  geometric cosine. A back-lit leaf's penumbra is 2× too wide. On a normal-mapped floor under a 30° sun the
  stretch goes from about 1.3 to 5 texel by texel, where the plane gives 2. This sets the shadow denoiser's
  reach (`seenSolidOf` → `penumbraIn` → `packShadowAlpha`).

## 9. Dark-map alpha left out of the haze — low

- **`components/rtxvulkan/shaders/lib/traversal.glsl:426` `candidateStops`** — confirmed.
  Shadow rays (`:444`) and bounce rays (`:454`) take a see-through surface's opacity from the diffuse
  alpha alone. `resolve` multiplies it by the dark map's alpha (`:1537`). The docs at `sampledOpacity`
  (`:180`) and `Surface::mOpacity` (`:1104`) say these are one number. A translucent pane whose dark map
  has alpha below 1 casts a shadow, and shows in reflections, denser than the pane itself. The comment at
  `:423` explains why the alpha cut skips the dark map, but the same read sets the haze.

## 10. Mirror — low

- **`components/rtx/mirror/chainkeys.cpp:23` `ChainKeys::under` / `retire`** — confirmed.
  A `StateSetUpdater` switches a node between two state-set copies at each update
  (`statesetupdater.cpp:36-39`). The walk keys each copy, and no material uses those keys. On each frame
  after a material is freed (`went.mMaterials > 0`), `retire` erases the copy not met, and the next frame
  makes it again: a `new osg::StateSet` and a map insert in the walk, for each such node in view. Non-AutoPlay
  NIF controllers (`nifloader.cpp:903`) and `GlowUpdater` cause it. This is a frame-path allocation.
- **`components/rtx/mirror/frozenroots.hpp:59` `FrozenRoots::Face`** — plausible.
  `Face::of` keeps the first child and the state set as raw pointers (`frozenroots.cpp:13-24`), with no
  hold. A replacement at the same address compares equal, and the root stays frozen with old placements.
  The identity keys use held pointers for this reason (`mirroridentity.hpp:21-24`). No shipped path found.

## 11. Device scene — low

- **`components/rtxvulkan/scene/devicescene.cpp:59` `DeviceScene::DeviceScene`** — plausible.
  The constructor records `SkinPass::record` once per pose copy, and each writes the same posed normals and
  tangents. The barrier between them (`posed()`) has a read-only destination access, so synchronisation
  validation reports a write-after-write. `SkinPass::recordArrived` has the write-to-write hand-over for the
  same case. The values are equal, so the picture does not change. The staged bind normals that
  `SceneBuffers::writeMeshes` writes, before the skin dispatch overwrites them, have the same shape.
- **`components/rtxvulkan/scene/bottomlevelstore.hpp:44` `Backlog::settle`** — plausible.
  The compaction backlog `mAsked` clears its read prefix only when it is fully read. While each frame asks a
  new question, it grows by one entry per structure built, with `push_back` reallocations on the frame
  path. `mAnswered` has the same shape, limited by the copy budget.

## 12. Traced ground: a reference moved into an interior — low

- **`apps/openmw/mwrender/rtx/tracedground.cpp:109` `TracedGround::blacklistReference`** — plausible.
  `World::moveObject` passes the Ptr from before the move, so the reference's new cell is computed from the
  new position in the old cell's worldspace. A reference moved from exterior cell C into an interior whose
  coordinates fall in C's square gives `now == content`, and the ring keeps it standing in the distance.

## 13. Vulkan device — low

- **`components/rtxvulkan/device/memory/image.cpp:357` `Image::buildMips`** — confirmed, latent.
  An image with one level is skipped, so no barrier orders its compute write before a sampled read. The
  doc in `image.hpp` promises that order. Current callers always pass more than one level.
- **`components/rtxvulkan/device/commands.cpp:614` `CommandPool::submitWithDeferred`** — plausible.
  With `mWatchSubmits`, each deferred batch is submitted alone first, but `mDeferred` is cleared only after
  the main submit succeeds (`:699`). If the main submit throws (`:658`) and the caller continues, the next
  submit sends the executed one-time buffers again.
- **`components/rtxvulkan/device/zonecounters.cpp:46` `ZoneCounters::ZoneCounters`** — plausible, latent.
  Counters are selected by pass count, and `VkPerformanceCounterKHR::scope` is not read. A
  command-buffer-scoped counter (ANV, Turnip) needs the query first and last in its buffer, and `GpuTimer`
  starts it in the middle (`gputimer.cpp:124`). RADV and NVIDIA are not affected.

## 14. Shader visitor auto maps — low, not on the accepted list

- **`components/shader/shadervisitor.cpp:300`, `automaps.cpp`** — confirmed.
  The move of upstream's auto normal and specular map code into `automaps` changed the rasterizer. In the
  `recreateShaders` path (`setAllowedToModifyStateSets(false)`), the specular map now takes unit N+1, where
  upstream wrote it over the normal map at N. `coordinatesFor` now skips unit 7 where upstream bound it as
  unit 0. Commits `99406b8529`, `3d5f1a73c1`.

## 15. SPIR-V pinning — low, latent

- **`components/rtxvulkan/spirv/spirvpin.cpp:279` `isUnpinnable`** — confirmed.
  The doc says every float atomic and subgroup reduction is refused. `OpAtomicFMinEXT`, `OpAtomicFMaxEXT`,
  `OpGroupNonUniformFMin/FMax` and `OpGroupFMin/FMax` pass through. No shader uses them now.
- **`components/rtxvulkan/spirv/spirvpin.cpp:521` `Pinner::survey`** — confirmed.
  `RelaxedPrecision` is refused only from `OpDecorate`. From `OpMemberDecorate` (a `mediump` block member)
  it is accepted. No shader uses `mediump` now.

## 16. Measurement — low

- **`apps/rtxtool/instruments/frametimes.cpp:497` `GpuBreakdown::add`** — confirmed.
  A counter row reserves one reading per frame (`:440`, `:469`, `:492`), but `insert` runs once per span,
  before the merge to one sample per frame (`:504`). A zone that opens more than once per frame (`tlas`)
  outgrows the reserve and reallocates in a measured frame, which the comment in `reserve` forbids.
- **`apps/rtxtool/cameradriver.cpp:243` `CameraDriver::fly`** — confirmed.
  `mArrived` is set on the step after the eye reaches `route.mTo`. A route that arrives early adds one more
  measured frame with the camera stopped at its end.
- **`components/rtx/renderer/nullrenderer.cpp:179` `NullRenderer::resultOf`** — confirmed.
  The null backend resolves the reconstruction at collection from the profile. It ignores
  `FrameOptions::mReconstruction` and a `setUpscale` made after the trace. `VulkanRenderer::traceFrame`
  resolves it at trace time.

## 17. OpenGL water cull — low, OpenGL renderer only

- **`apps/openmw/mwrender/glworld.cpp:450` `GlWorld::describe`** — plausible.
  The water's height-cull callback is set again only when the water height or exterior/interior changes.
  Upstream set it at each cell load (`scene.cpp:511`). After a move between two ESM4 exterior worldspaces
  with the same water height, the water keeps the old terrain's callback, whose lowest point no longer
  updates, and can be culled whole.

## 18. Shader digest can throw — low

- **`components/rtx/renderer/shaderdirectory.cpp:27` `Rtx::digestShaders`** — plausible.
  The `error_code` goes only to the `directory_iterator` constructor. The loop's `operator++` throws
  `filesystem_error` on an iteration error, but the function must not throw (`getHash` is in a `try`).

## Question for the owner

- **`LightGrid` builds the whole grid again when the lamp count changes.** Its doc says so. AGENTS.md says
  work is incremental and never batched behind a threshold. A reviewer reported it as a design choice,
  not a bug.
